# EMEGE IA Solutions

Proyecto React + Vite + Tailwind preparado para Netlify.

## Desarrollo local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Netlify

- Build command: `npm run build`
- Publish directory: `dist`
- Node version: `20`

Este ZIP usa Tailwind CSS 3.4.17 fijado para evitar errores de PostCSS con Tailwind v4 en Netlify.
